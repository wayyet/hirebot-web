> 文档目的：基于《01-产品设计备忘录》《03-雇佣端详细需求规格说明书》整理雇佣端 MVP 功能范围、角色边界与模块清单
> 适用对象：产品、设计、研发、测试
> **版本**：v3.0
> - v2.0：飞书接入模式由模式 C 改为模式 A（每员工独立自建应用）

## 1. 产品定位与范围

雇佣端是三平台体系中唯一直接面向业务终端用户的平台，核心目标是让部门长和普通职员以最低门槛获得可在平台内或 IM 中实际工作的数字员工实例。雇佣端承接模板池和创世员工能力，负责实例化、评估、上岗、分身复制、私有分支、运行时管理、评分反馈。

雇佣端的四条核心业务主线：

1. **部门版雇佣**：部门长基于模板完成完整六大步骤，产出已上岗的部门版数字员工。
2. **部门长快捷复制**：部门长从已上岗的部门数字员工中快速复制，产出新的部门员工，免评估直接发布。
3. **分身复制**：普通职员或部门长基于已上岗部门版快速复制个人分身，完成 IM 绑定后立即可用。
4. **私有分支**：用户基于自己的分身做个性化定制，评估通过后切换到私有分支版本继续使用。

## 2. 角色与边界

| 角色 | 核心目标 | 关键权限 | 关键限制 |
|---|---|---|---|
| 部门长 | 雇佣部门版、快捷复制部门员工、评估、上岗、处理反馈 | 浏览模板池、发起部门版雇佣、快捷复制部门员工、执行人工评估、查看部门聚合反馈、创建私有分支、复制分身 | 不能查看他人的私聊内容、不能修改创世员工、不能上传私有 skill |
| 普通职员 | 复制分身、在平台或 IM 中使用、打分反馈、可选创建私有分支 | 浏览本部门已上岗部门版、复制分身、配置 IM、提交评分反馈、创建自己的私有分支 | 不能浏览企业模板池、不能查看他人数据、不能跳过评估创建私有分支 |

## 4. 分模块详细说明

### 4.1 全局框架与权限

- 角色化工作台：部门长侧重模板雇佣、部门员工管理、待处理反馈；普通职员侧重我的分身、可复制部门版、站内对话入口。
- 实例状态统一管理：所有部门版、分身、私有分支都受统一状态机管理。
- 数据隔离：同租户内也必须做用户级隔离；部门长不能查看下属与数字员工的具体对话内容。

### 4.2 模板池与部门版雇佣

- 部门长可浏览来源于平台一和构建端的模板池。
- 部门版雇佣的唯一前台入口位于企业模板详情内页，由用户点击"雇佣"开始。
- 雇佣流程采用"对话引导 + 六步流程"的形式。
- 外部对接阶段必须包含连接测试。

### 4.3 部门长快捷复制部门员工（新增）

- 部门长在「部门数字员工」列表中，选择一个已上岗的部门员工点击「创建分身」。
- 系统快照拷贝五件套，生成新实例，`instance_type=department`，继承源实例的评估结果，免评估直接上岗。
- 发布到部门数字员工列表，全部门成员可见，可继续被复制分身。
- 完成后显示引导弹层：「已为部门创建了新员工，要为自己复制一个体验吗？」，引导部门长进入分身复制向导。
- `from_instance_id` 记录来源实例，用于审计追溯。

### 4.4 AI评估与人工评估

- 参见《需求规格说明书》第 7 节，完整流程不变。
- 快捷复制的部门员工不进入评估（继承源实例评估结果）。

### 4.5 Review

- 与部门版雇佣流程共用 Review 机制，参见《需求规格说明书》第 8 节。

### 4.6 多平台 IM 接入（更新）

- 支持三个 IM 平台：**飞书**、**钉钉**、**企微**。
- 同一数字员工可同时配置多个平台，各平台独立运行。
- 接入逻辑（各平台一致）：
  1. 平台展示该实例专属 Webhook URL
  2. 用户去对应平台创建机器人，获取凭证
  3. 将凭证回填到平台对应平台的配置表单
  4. 平台发起连接验证，通过后该平台渠道激活
- 各平台凭证字段：
  - **飞书**：app_id、app_secret、verification_token
  - **钉钉**：app_key、app_secret、（企业内部应用还需 corp_id）
  - **企微**：corp_id、agent_id、agent_secret、token、encoding_aes_key

### 4.7 站内对话（新增）

- 用户在「我的数字员工」列表直接点击员工卡片，进入站内对话界面。
- 站内对话是平台提供的**主使用渠道**，不依赖外部 IM 配置即可使用。
- 保存对话历史，支持查看历史记录。
- IM 渠道作为**补充使用渠道**，需额外配置机器码。

### 4.8 快捷 IM 通道（新增）

- 员工卡片和详情页提供「配置 IM」和「去 IM」两个快捷按钮。
- **「配置 IM」**：进入 IM 机器码配置页，选择平台并填写凭证。
- **「去 IM」**：
  - 已配置至少一个平台 → 若只有一个平台直接跳转；若多个平台，弹出选择器让用户选择渠道
  - 未配置任何平台 → 显示引导提示「尚未配置 IM，前往配置？」，点击进入配置页

### 4.9 分身复制

- 三步内完成：确认复制 → 配置个人信息 → 上岗（IM 配置可选，上岗后仍可随时配置）。
- 分身复制继承母版评估结果，不进入双阶段评估。

### 4.10 私有分支

- 私有分支复用原分身的 IM 配置，平台内部切换路由，用户 IM 体验不变。
- 私有分支有独立的站内对话记录，与原分身隔离。

### 4.11 评分与反馈

- 站内对话和 IM 对话都支持评分。
- 部门长看聚合统计，不能下钻到具体对话内容。

## 6. 关键产品约束

| 约束项 | 约束说明 |
|---|---|
| 一对一私聊 | 数字员工在 IM 中只能私聊使用，不支持群聊 |
| 分身快照独立 | 分身复制后与母版脱钩，不做级联升级 |
| 严格评估门槛 | 部门版雇佣与私有分支必须经过 AI 评估和人工评估；快捷复制继承源实例评估结果免评估 |
| 无私有 skill 上传 | 不能直接上传或编写 skill |
| 私有分支不套娃 | 私有分支不可二次分支 |
| 隐私优先 | 部门长只能看聚合反馈，不能看下属具体对话 |
| 多平台 IM 独立 | 每个 IM 平台配置独立，互不影响；可同时激活多个平台 |
| 站内对话不替代 IM | 站内对话是主渠道，IM 是可选补充渠道，两者并存 |
